# E-TAILED Digital Studio

Build a single-page React + Vite + Tailwind website for E-TAILED DIGITAL INDIA, inspired by the premium editorial quality of Squarespace, but do NOT copy its branding, text, logos, or images.

Use the exact design/content/specifications from the provided full brief. Keep the site dark, warm, minimal, editorial and premium.

Colors: Navy #0d2033, darker navy #06131f/#0a1a29, Nutmeg #a86f4d, light nutmeg #c18b69, warm text #ece4da. Never use white backgrounds, teal, cyan, turquoise, generic blue, or heavy beige.

Fonts: Inter + Instrument Serif italic for accents.

Implement all sections and functionality exactly as specified:

Fixed responsive navigation + mobile fullscreen menu

Fullscreen parallax hero with headline, CTAs and stats

Infinite marquee

8-service editorial list with hover interactions, images and detail modals

About section with parallax background

4-step Process section

Contact CTA with email + WhatsApp

Footer with oversized outlined E-TAILED wordmark

Smooth scrolling, IntersectionObserver reveal animations, stagger effects and parallax

Respect prefers-reduced-motion

Fully responsive down to 360px

Semantic HTML, accessibility, focus states and alt text

Use Lucide icons only

Use real Unsplash images with dark overlays

No card-grid/template aesthetic; use large typography, hairlines, whitespace and editorial layouts.

Use the exact service names, descriptions, bullets, text, colors, spacing, interactions, links and section structure from the full brief. Keep services in one data array and components cleanly separated (Nav, Hero, Marquee, Services, ServiceModal, About, Process, Contact, Footer).
